ConnectU is a console based social network application I developed for ECE 367L, Computer Data Structures and Algorithms. The project models core social media features, including user profiles, posts, friendships, and personalized feeds. User, relationship, and post information is stored in CSV files, allowing the program to simulate a small persistent social network database. The application applies the data structures and algorithms from class to organize and retrieve that information efficiently.

I independently designed and implemented the underlying data structure components of ConnectU. The application uses linked lists to manage each user timeline, a hash map to look up users by username, a binary search tree to organize friends, and a graph to represent friendship connections. Breadth first search identifies friend of friend recommendations, while a max heap prioritizes posts for the feed. I used C++ to connect these features into a single menu driven application.

This project strengthened my understanding of how selecting the right data structure affects an application. Linked lists make timeline insertion efficient, hash maps support fast account lookup, trees allow ordered traversal, graphs model social relationships naturally, and heaps support feed ranking. I also gained hands on experience with pointers, dynamic memory, object oriented design, CSV file input and output, and breaking a larger program into smaller maintainable components. ConnectU showed me how fundamental algorithms can support features people expect from real social platforms.
