When developing a website, HTML and CSS are usually the first things that developers learn. HTML provides the structure of a webpage, while CSS controls how everything looks. However, as websites become more complicated, writing CSS for every individual element can become time consuming. This is where UI frameworks such as Bootstrap 5 become useful. Although learning a framework can be confusing at first, I think it is worth the effort because it makes building websites easier and saves developers time.

## Getting Started with Bootstrap

Before learning Bootstrap 5, I was somewhat comfortable using HTML and CSS. I understood how to create basic webpages and apply styling, but I was not that experienced with building more complicated layouts. When I was first introduced to Bootstrap, I thought it seemed convenient because it already had many features that would normally require additional CSS. Instead of having to style everything from scratch, I could use Bootstrap classes to make elements look better without having to write as much code.

One feature that I found useful was Bootstrap's navigation bar. Creating a navigation bar using only HTML and CSS is possible, but making it look organized and work properly on different screen sizes can take some time. Bootstrap makes this process easier by providing classes that handle much of the styling. I think this is one of the main reasons why someone would want to use a UI framework. Instead of spending time figuring out how to make every element look right, developers can use components that are already available and focus on other parts of their website.

## Making Sense of Rows and Columns

However, Bootstrap was not always easy to understand. One part that confused me was the grid system, especially how rows and columns work together. Bootstrap uses a 12-column grid system to organize content, which is different from how I was used to creating layouts with CSS. For example, a class such as `col-md-6` makes an element take up half of the available row on medium-sized screens and larger. At first, remembering how these classes worked and how the rows and columns interacted was confusing. Even though the system is supposed to make designing layouts easier, I still had to spend time understanding how to use it properly.

## One Website, Different Screens

Another useful part of Bootstrap is its support for responsive design. Nowadays, people use different devices to access websites, such as phones, tablets, and computers. Because of this, a website should be able to adjust to different screen sizes without everything looking out of place. Normally, developers would have to write their own CSS media queries to handle these changes. Bootstrap already provides responsive classes that can help with this. I think this is helpful because it reduces the amount of CSS needed, especially when working on websites that have multiple sections or complicated layouts.

## Keeping a Team on the Same Page

Besides making development easier, Bootstrap also has benefits when it comes to software engineering. One example is consistency. If multiple people are working on the same website, they might have different ways of styling buttons, navigation bars, and other elements. This could make the website look inconsistent and harder to maintain. By using Bootstrap, developers can follow the same set of classes and design conventions. This makes it easier to keep everything looking similar and can also make it easier for other developers to understand the code.

## Knowing When to Write My Own CSS

Even though Bootstrap has many advantages, I do not think it completely replaces HTML and CSS. Understanding HTML and CSS is still important because Bootstrap is built using them. There are also situations where writing your own CSS might be better, especially if you want your website to have a unique appearance. Using Bootstrap for everything could also make websites look too similar because they rely on the same default components. I think it really depends on what kind of website someone is trying to create and how much customization they need.

## Is the Learning Curve Worth It?

After using Bootstrap 5, I can see why developers choose to use UI frameworks instead of writing everything with HTML and CSS. Although I initially struggled with understanding the rows and columns, I still found features like the navigation bar convenient. I also think having responsive features already available is useful because developers do not have to create everything themselves. While learning Bootstrap does require some extra effort, the time saved during development makes it worthwhile. I would rather spend some time learning how a framework works than repeatedly write the same CSS for features that Bootstrap already provides.
