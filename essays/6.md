# Manoa Rest Stop: A UH Manoa Bathroom Locator and Tier List

### The problem

Many UH Manoa bathrooms are dirty or have a strong odor, while others are clean or newly renovated. Students often enter a bathroom without knowing its condition, which can lead to a bad experience. There is no central website where the UH community can compare bathrooms before using them.

### The solution

Manoa Rest Stop will be a website with information about bathrooms across UH Manoa. It will use Next.js, React, Bootstrap 5, and GitHub. Each bathroom page will include basic information such as:

- Last renovation date, bathroom type, number of stalls, location, and number of favorites.
- Average star rating, cleanliness rating, odor rating, and user comments.
- Recent cleanliness reports, which will be separate from the overall rating because conditions can change throughout the day.

Users will be able to search for bathrooms, view them on an interactive map, and save favorites. After logging in, each user will have a personal list of favorites, reviews, reports, and bathroom requests. This individual user state is the application's special sauce.

### Roles

- **Users:** Submit reviews and recent cleanliness reports, favorite bathrooms, request new bathroom locations, and request changes to bathroom information.
- **Admins:** Have all user privileges and approve bathroom requests, static-data changes, reviews, and reports.

## Mockup page ideas

- Landing page: Explain Manoa Rest Stop and let users browse, log in, or register.
- Interactive map and bathroom list: Show bathroom locations with search, filters, favorite counts, and tier rankings.
- Bathroom detail page: Show basic data, ratings, recent cleanliness reports, comments, and a favorite button.
- Rating and request forms: Let users submit ratings, cleanliness reports, new bathroom requests, and data-change requests.
- User and admin dashboards: Show a user's favorites and submissions, while allowing admins to approve or reject requests.

## Use case ideas

- A user searches the map for a nearby bathroom and checks its odor, cleanliness, renovation date, and recent reports.
- A user logs in, favorites a bathroom, and views all of their saved bathrooms on their dashboard.
- After using a bathroom, the user submits a star rating, cleanliness rating, odor rating, and optional comment.
- A user submits a recent cleanliness report or requests a new bathroom location or data correction.
- An admin reviews and approves or rejects bathroom requests, data changes, reviews, and reports.

## Beyond the basics

- Add building hours, accessibility information, and directions to each bathroom.
- Use a tier list to rank bathrooms based on community ratings and recent reports.
- Send notifications when a favorite bathroom receives a new report or its rating changes.
- Add charts showing how cleanliness and odor ratings change throughout the day.
- Add moderation tools and community guidelines to keep reviews useful and respectful.

Because bathroom conditions and reviews can change, the application should show when information was last updated and avoid displaying users' exact locations.
